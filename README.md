# 💰 ExpenseHub

**Smart Expense Tracker with AI & OCR**

Catat pengeluaran harian dengan mudah. Scan struk, AI parsing otomatis, dan kelola keuanganmu dengan lebih pintar.

## 🚀 Features

- 📸 **OCR Scan Struk** - Foto struk, data otomatis terekstrak
- 🤖 **AI Parsing** - Intelligent data extraction
- 📍 **Location-Based** - Quick add saat di tempat langganan
- 📊 **Smart Insights** - Laporan keuangan bahasa natural
- 🔒 **Privacy-First** - Data tersimpan lokal di perangkat

## 📥 Installation

```bash
git clone https://github.com/faidlurrohman/ExpenseHub.git
cd ExpenseHub
npm install
npm run start
npm run android
```

## 🛠️ Tech Stack

- React Native
- Firebase Analytics
- Google ML Kit (OCR)
- Gemini AI API
- AsyncStorage
